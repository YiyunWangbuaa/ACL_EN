# 天平系到风轴系：每一问的程序处理方法

这份说明只核对 `tp_fd_generate.py` 怎样从一份约束声明得到 `TP_FD.md` 的 52 个空。它不列出某一份声明下的具体答案。程序先刷新机体模型，使用天平轴、风轴、体轴、安装方式、γ_tp、三个弹性角、理论姿态角和两个气流偏心角。

被动矩阵与绝对方向向量与另外两个坐标系过程相同。弹性角的小角度近似只用于天平轴向单位向量：sinθ 取 θ，cosθ 取 1，并且只保留到弹性角的一次项。安装角 γ_tp 仍用完整的正弦和余弦。γ_e 是绕轴向的扭转，一次项不改变轴向单位向量，所以变形向量里不出现 γ_e。

建议先核对文末的方法选择。安装方式会改变模型上的增量符号，但不会改变天平轴到风轴的对齐矩阵。

## 步骤 1

**ID 1、2。** 固定填写。弹性角增量从天平系转到风轴系。

**ID 3、4、5。** 给风轴系的法向、侧向、轴向找有方向轴。法向的正方向是上，侧向的正方向是右，轴向的正方向是前。哪根坐标轴与该方向同向，就写这根轴的名字；哪根轴与它反向，就写这根轴的名字并加上负号。顺序是法向、侧向、轴向。

**ID 6、7、8。** 同一规则，对象换成天平系。

**ID 9，RP_TP_FD。** 不使用安装方式，也不使用 γ_tp。矩阵第 i 行第 j 列是风轴第 i 轴与天平第 j 轴方向向量的点积。行顺序 XFD、YFD、ZFD，列顺序 XTP、YTP、ZYP。它只表示两个坐标系在平置时的轴对齐。

**ID 10。** 固定填写天平系。意思是这个矩阵对齐的是天平系的坐标轴方向。

**ID 11。** 固定填写风轴系。本过程的终点就是风轴系，程序不再从矩阵内容反推另一个坐标系名字。

## 步骤 2

**ID 12。** 读取 γ_tp 所绑定的天平轴，把它的绝对角色写成轴向、法向或侧向。按定义，安装角绑在天平轴向轴上，所以角色是轴向。坐标轴具体叫哪一个名字留给下一问。

**ID 13。** 输出上一问那根轴的坐标名。

**ID 14。** 读取安装角相对该轴正方向是正转还是负转。声明与右手定则相同时为正转，写正；相反时写逆。

**ID 15。** 取 ID 13 那根轴的被动旋转矩阵。正转时转角为 γ_tp，负转时转角为 −γ_tp，再化简。

## 步骤 3

**ID 16。** R1 是 ID 9 的 RP_TP_FD。它在安装角旋转之后作用，所以放在连乘式左边。

**ID 17。** R2 是 ID 15 的安装角矩阵，最先作用，放在右边。

## 步骤 4

**ID 18。** 未变形的天平轴向单位向量，取天平“前”这个绝对方向，写成 XTP、YTP、ZYP 三个分量。每个分量是该方向与对应天平轴的点积。轴向坐标轴若指向后，前方向在该轴上的分量就是 −1。

**ID 19、20。** 读取 α_e、β_e 经过符号处理后的实际弯曲方向，再译成上、下、左、右、前、后。声明若把正号定义在相反一侧，这里输出的是反号之后的方向。不经过模型正装或反装。

**ID 21。** 读取 γ_e 绕其旋转轴是正转还是负转。正转写顺时针，负转写逆时针。程序采用的观察方向是沿该轴正方向看去，也就是轴的正向离开观察者；这时右手定则的正转表现为顺时针。γ_e 的转向本身仍由模型计算：轴向正转把天平右侧带向“轴向 × 右”，再与弹性滚转声明的移动方向比较。

**ID 22、23、24。** 读取三个弹性角已经绑定的天平坐标轴。模型的绑定是固定角色：α_e 绕侧向，β_e 绕法向，γ_e 绕轴向。答案是承担该角色的坐标轴名字。

**ID 25、26、27。** 先写小角度变形向量，再判断符号。向量等于未变形轴向分量，加上 α_e 乘“α_e 弯曲方向”的天平分量，再加上 β_e 乘“β_e 弯曲方向”的天平分量。三个空按 XTP、YTP、ZYP 的顺序。某一分量若有非零常数项，符号由常数项决定。常数项为零时，看 α_e 和 β_e 的一次系数：都为正写正，都为负写负，一正一负或都为零写不确定。

**ID 28。** 输出 ID 25 到 27 所用的同一个向量，保留 α_e 和 β_e 的符号，不再只写正负。

## 步骤 5

**ID 29、30、31。** 用 ID 16 和 ID 17 的矩阵左乘 ID 28 的列向量，得到风轴坐标。XFD、YFD、ZFD 依次是三个分量的化简表达式。这里的 γ_tp 仍是准确转角，弹性角保持一次近似。

## 步骤 6

角度的符号由理论姿态角决定，不在这一步读取弹性角。理论角的正空速方向取反，得到使该角为正的机头方向，再按安装方式放进风洞。

用风轴分量表示的公式是：该风洞机头方向上的投影，除以风洞正前方的投影。投影把 XFD、YFD、ZFD 按各风轴的实际指向合成。

**ID 32。** 取迎角公式分子里出现的那一个风轴分量名字。分母所在的轴不作为这一问的答案。

**ID 33。** 对侧滑角重复上一问。

## 步骤 7

这一步的模型增量和后面的风轴分量符号是两条分开的判断。

增量来自模型里的弹性角到姿态角映射：

- 迎角和侧滑角：天平轴向弯向声明方向，所以空速偏向该方向映到机体后的反方向。
- 滚转：天平右侧在正装时仍是机体右侧，右翼就按声明方向移动。反装时右翼换到天平左侧，上下也交换，两处反向互相抵消。
- 增量符号：上述机体效果与理论角的正方向相同则写正，相反则写负。理论角没有声明时写不确定。

**ID 34。** 读取安装方式。upright 写正装，inverted 写反装。

**ID 35、36、37。** 分别读取 Δα、Δβ、Δγ 的机体效果方向。35 是迎角造成的空速上下，36 是侧滑造成的空速左右，37 是滚转造成的右翼上下。

**ID 38、39、40。** 直接读取理论迎角、理论侧滑角的正空速方位，以及理论滚转的右翼方位。这三问不经过安装方式。

**ID 41、42、43。** 读取上面三条增量的正负号。顺序是 Δα_e、Δβ_e、Δγ_e。

**ID 44、45、46。** 把 ID 29 到 31 的表达式里 γ_tp 设为 0，再用 ID 25 的规则判断 XFD、YFD、ZFD。这一问表示天平轴向在风轴里的分量，不是空速分量。它使用天平到风轴的几何关系，不因为反装而改用增量符号。

## 步骤 8

**ID 47、48。** 输出步骤 6 已经建立的两个比值，迎角在前，侧滑角在后。比值由风轴分量 XFD、YFD、ZFD 组成，正负号来自理论机头方向和安装方式。

**ID 49、50。** 把 ID 29 到 31 的弹性角表达式代进这两个比值并化简。因此结果是 α_e、β_e 和 γ_tp 的组合。γ_e 不出现。

## 步骤 9

**ID 51、52。** 比较气流偏心角与对应理论角的正空速方向。两者是同一个机体方向时，偏心使实际角度增大，符号写正；是相反方向时写负。比较在机体方向之间进行，不经过安装方式。51 是迎角，52 是侧滑角。

## 建议优先核对的方法选择

1. RP_TP_FD 只对齐平置的天平轴和风轴，反装不进入这个矩阵。反装进入的是模型迎角、侧滑角增量的符号，以及 ID 47 到 50 的机头投影方向。
2. 沿轴向正方向看去时，程序把绕轴正转写成顺时针。
3. 变形轴向向量只含 α_e 和 β_e 的一次项。γ_e 不改变这个向量。
4. ID 44 到 46 是 γ_tp 为零时风轴分量的正负，ID 41 到 43 是姿态增量的正负。反装可以让二者不一致。
5. Δα_e、Δβ_e 用“正机头方向的风洞投影 / 风洞前方投影”，并且已经用小角度条件去掉了反正切。
6. Δα_V、Δβ_V 只比较偏心角和理论角的机体正方向，不乘弹性角矩阵。
