## 步骤 1

- ID 1 [C2] 体轴系原点所在位置（天平校心/机体质心/风洞原点）：天平校心
## 步骤 2

- ID 2 [A1] 天平校心到模型顶点的距离 Xr：L + L_t - L_r
## 步骤 3

- ID 3 [C1] 与体轴数学坐标正方向定义不同的工程分量（Xg/Yg/Zg）：Xg
- ID 4 [A1] 力矩参考点的体轴数学坐标：[Xr - Xg, Yg, Zg]
## 步骤 4
