# 转向复核：α 的修复与同类问题

对象：`domains/aerodynamics/` 三个子过程（当前为 1–28 / 29–69 / 70–104 的连续编号，pilot 104 空）

## 1. 结论

- 你指出的 85 空（迎角转向）已经正确：正迎角给出 **逆向**，`Sα` 为 `[[cos α, 0, sin α], [0, 1, 0], [-sin α, 0, cos α]]`，与“空速投影在机体轴下方”一致。
- 检查又发现同类的第二处：**侧滑角 β 仍用旧的被动取负号规则**，正侧滑给出“逆向”，`R_β`、`Sβ`、`Sαβ` 的符号都跟着反。已改为与 α 相同的规则：正侧滑为 **正向**，`R_β = [[cos β, sin β, 0], [-sin β, cos β, 0], [0, 0, 1]]`。
- 改完后，体轴系到气流系的 `Sαβ` 正好等于标准方向余弦矩阵
  `[[cos α cos β, sin β, sin α cos β], [-sin β cos α, cos β, -sin α sin β], [-sin α, 0, cos α]]`。

## 2. 判据

转向只由定义决定：正角把定义里写的那根向量转向声明的一侧，因此

```text
转向 = sign( cross(旋转轴, 运动向量) · 目标方向 )
```

- 旋转轴：该角所在有向转换的**起点系**里，与角的绝对方向轴重合的那根坐标轴（先用绝对方向，再推断坐标轴）；
- 运动向量：定义里的 `moving`（迎角/侧滑是空速，姿态角是机头或右翼）；
- 目标方向：定义里的 `toward`，声明为负时取反。

这条规则不依赖模型里的 kind 标记，正好可以独立复核。
