# 风洞业务：角度绑定思路检查与重构

对象：`body_frame_model.py` 与 `domains/wind_tunnel/` 下的生成数据（`batch_100`、`review_10`、`stress_10`、四份 `*_eval` 文档）

## 1. 检查结论

**是的，风洞业务原来就是“先判定绝对方向轴，再由定义推导坐标轴”，但写法是反的：角挂在轴上，而不是轴由角推出来。**

具体看三处：

- `ANGLE_ABOUT_ABSOLUTE_AXIS = {LATERAL: ALPHA, NORMAL: BETA, AXIAL: GAMMA}`（274 行）——α/β/γ 只按绝对方向定义；
- `ABSOLUTE_AXIS_OF_MECHANISM`（279 行）、`FLOW_SPEC`（243 行）、`ELASTIC_SPEC`、安装角的 `axial_absolute`——机制角、气流角、弹性角、安装角也都先给绝对方向，再在坐标系里找 `absolute_axis` 相同的那根轴；
- `_build_frame`（831–845 行）把 `axis.associated_angle = ANGLE_ABOUT_ABSOLUTE_AXIS[absolute_axis]`，即“轴声明了绝对方向，角被挂到轴上”。

所以判断链一直是“绝对方向 → 坐标轴”，只是**数据存放在轴上**：`AxisRecord.associated_angle` 存角，`AngleRecord` 上只有 `associated_axis`，没有 `absolute_axis`。这正是与飞行力学模型写法不一致的地方。

另外，风洞只有单向变换（`wind → body`、`balance → body`），没有正反向之分，所以不需要飞行力学那边的“双向绑定”；这次统一的是“绝对方向优先”的写法。

## 2. 重构

`body_frame_model.py`：

1. `AngleRecord` 增加 `absolute_axis` 字段（426 行），与 `associated_axis` 并列。
2. 新增两个辅助方法（1047、1054 行）：
   - `_axis_on_absolute(frame, absolute_axis)`：按绝对方向找该系的坐标轴；
   - `_bind_to_absolute(record, frame, absolute_axis)`：先写 `record.absolute_axis`，再推断 `record.associated_axis`，返回该轴或 `None`。
3. 所有角度绑定都走这两步：
   - α/β/γ：`_build_frame` 建轴时同时写入角的 `absolute_axis` 与推断出的 `associated_axis`；
   - 机制角 α_M、β_M、γ_M：`_bind_rotations` 用 `_bind_to_absolute`；
   - 气流角 α_V、β_V：`_bind_flow_rotations` 用 `_bind_to_absolute`；
   - 弹性角 α_e、β_e、γ_e：`_bind_elastic` 用 `_bind_to_absolute`；
   - 安装角 γ_tp、γ_model：`_bind_installation` 先写 `record.absolute_axis = axial_absolute`，再推断轴。
4. `describe()` 与 `_append_angle` / `_append_elastic` 的输出改成 `absolute body_lateral -> ZTZ` 这种形式，和飞行力学模型的 `绝对方向 → 坐标轴` 一致。

生成器无需改动：`domains/wind_tunnel/*.py` 本来就用 `record.associated_axis` 或 `axis.absolute_axis`。

## 4. 与飞行力学模型的对应

| 维度 | 飞行力学 `flight_frame_model.py` | 风洞 `body_frame_model.py` |
| --- | --- | --- |
| 绑定顺序 | 绝对方向 → 坐标轴 | 绝对方向 → 坐标轴（本次补齐） |
| 方向 | 有正反向，逆向只把转向取反 | 只有单向（风洞→机体、天平→机体），无需反向 |
| 记录位置 | `TransformBinding.absolute_axis` / `.axis` | `AngleRecord.absolute_axis` / `.associated_axis` |
| 展示 | `绝对方向 body_lateral → 机体的 Yb` | `absolute body_lateral -> ZTZ` |
