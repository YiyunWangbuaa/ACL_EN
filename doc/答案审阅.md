# 空气动力学子过程：答案审阅与双向绑定修复

> 更新：数据编号已改为连续 1–28 / 29–69 / 70–104（pilot 104 空），地面系法向正方向统一为“向下”，迎角与侧滑的转向按定义取号。本文引用的旧计数（27 空、247/287/250 条等）是历史版本；最新结论与复核见 [转向复核.md](转向复核.md)。

对象：`domains/aerodynamics/` 下三个子过程的数据（地面→机体、地面→航迹→气流、机体→气流）

## 0. 结论

- 审阅发现：8 个角的旋转矩阵里有 6 个写在了错误的坐标系，非默认轴排列的样本里复合矩阵绕错物理轴。
- 已修复：角度先绑**绝对方向轴**（如 `body_lateral`），再由坐标轴与绝对方向的对应关系**推断**具体坐标轴（如 `Yb`）；每个有向转换只用**起点与终点**两个坐标系，不参考中间状态。
- 上一轮修复改了 247 / 287 / 250 条答案；本轮把绑定改成“绝对方向 + 起点/终点”之后，**答案零变化**（三个 batch 与 pilot_10 的哈希与重构前完全一致），说明上一轮的答案就是这套规则的结果。

## 1. 修复前的证据

### 1.1 判据

被动旋转绕某根轴转动时，该轴上的坐标方向必须原地不动。把复合矩阵里除被测角以外的角置零，检查 `S·(起点系该轴) = (终点系该轴)`。该判据不依赖左右手、正负号或被动/主动的约定。

### 1.2 修复前的失败样本

| 子过程 | 角 | 不变量 | 失败 |
| --- | --- | --- | --- |
| 地面→机体 | ψ 偏航 | 保持法向 | 0 / 40 |
| 地面→机体 | θ 俯仰 | 保持侧向 | 20 / 40 |
| 地面→机体 | Φ 滚转 | 保持轴向 | 17 / 40 |
| 地面→航迹→气流 | φ 方位 | 保持法向 | 0 / 48 |
| 地面→航迹→气流 | μ 倾斜 | 保持侧向 | 26 / 48 |
| 地面→航迹→气流 | γ 滚转 | 保持轴向 | 24 / 48 |
| 机体→气流 | α 迎角 | 保持侧向 | 22 / 40 |
| 机体→气流 | β 侧滑 | 保持法向 | 24 / 40 |

反例（地面→机体，样本 1-01，纯俯仰 10°）：地面 `Zg` 沿侧向指左（侧向槽位是 Z），机体侧向是 Y。修复前的总矩阵把地面侧向 `(0,0,1)` 映射到 `(-0.174, 0.985, 0)`，而它应当原地映射到 `(0,1,0)`——绕侧向轴的旋转把侧向轴本身转歪了 10°。

## 2. 绑定规则

### 2.1 先绝对方向，后坐标轴

每个角保存的是**绝对方向轴**，例如 θ 存 `ground_lateral`、β 存 `stability_normal`。具体坐标轴不在声明里出现，而是从“坐标轴 ↔ 绝对方向”的对应关系推断：

```text
绝对方向 ground_lateral  →  该声明里指向侧向的那根地面坐标轴，可能是 Yg，也可能是 Xg 或 Zg
```

`TransformBinding` 里同时保留 `absolute_axis`（绝对方向）与 `axis`（推断出的坐标轴），`AxisRecord.absolute_axis` 是声明时写入的对应关系，`_axis_on(owner, absolute)` 完成推断。

### 2.2 只看起点和终点

对每个有向转换 `origin → destination`：

- 角度绑在**起点系**（`origin`）的绝对方向轴上；
- 逆变换（`inverse=True`）只是把正角转向取反，起点仍是 `origin`（它就是正向的终点）；
- **不参考中间坐标系**。

因此：

- 地面→机体：ψ、θ、Φ 用地面方向（`ground_normal` / `ground_lateral` / `ground_axial`）；
- 机体→地面：同一组角用机体方向；
- 机体→气流（直接变换）：α 用 `body_lateral`，β 用 `body_normal`，**不经过稳定性坐标系**；
- 稳定性→气流（分段变换）：β 用 `stability_normal`；
- 机体→稳定（分段变换）：α 用 `body_lateral`；
- 地面→气流：φ、μ、γ 全用地面方向，γ 不绑到航迹系。

`DIRECTED_TRANSFORMS` 里因此同时保留了分段变换（body→stability、stability→airflow 及其反向）与直接变换（body→airflow 及其反向）。

### 2.3 模型的实际绑定表

`python analysis/audit_aerodynamics.py` 输出（`frame` 是矩阵所在坐标系，`absolute` 是绝对方向，`axis` 是推断出的坐标轴）：

  body   -> ground     theta    frame=body       absolute=body_lateral     axis=Yb  negative
  body   -> ground     phi      frame=body       absolute=body_axial       axis=Xb  negative
  ground -> airflow    varphi   frame=ground     absolute=ground_normal    axis=Zg  positive
  ground -> airflow    mu       frame=ground     absolute=ground_lateral   axis=Yg  positive
  ground -> airflow    gamma    frame=ground     absolute=ground_axial     axis=Xg  positive

## 3. 代码改动

`flight_frame_model.py`：

1. `AngleSpec` 保留 `pair`（角自身的两段坐标系，供 `binding()` 使用），`frame` 是只读属性 `pair[0]`。
2. `TransformBinding` 增加 `absolute_axis` 字段：先存绝对方向，再存推断出的 `axis`。
3. 新增 `_axis_on(owner, absolute_axis)`：按绝对方向找该系的坐标轴；`_axis_for(name, frame)` 只是 `_axis_on(frame, f"{frame}_{role}")` 的包装。
4. `_bind_transforms()` 改为：`start = origin`，绝对方向 `f"{start}_{role}"`，轴由 `_axis_on` 推断，转向按该轴求，`inverse` 只取反转向。
5. `DIRECTED_TRANSFORMS` 增加分段变换：`body→stability`、`stability→body`、`stability→airflow`、`airflow→stability`；`body→airflow` 仍是直接变换。
6. `_append_transform()` 打印“绝对方向 → 坐标轴”；`describe()` 说明“先绝对方向、后坐标轴”与“只看起点终点”两条规则。
7. `_check()` 自检改为断言全部 14 条有向转换的起点系、绝对方向、坐标轴与转向。

生成器：

- `body_air_generate._record()` 改为在**分段变换**上取绑定（`body→stability` 取 α，`stability→airflow` 取 β），分段矩阵各自写在自己的起点系。
- `ground_body_generate` / `ground_track_air_generate` 本来就用 `conversion(origin, destination)`，无需改动。

## 4. 验证

### 4.1 不变量

三个子过程、8 项检查全部 0 失败：

```text
ground_to_body       yaw 0/40   pitch 0/40   roll 0/40
ground_to_track_air  azimuth 0/48   inclination 0/48   bank 0/48
body_to_airflow      alpha 0/40   beta 0/40
```

### 4.2 结构

- 条数 40 / 48 / 40，每样本 27 / 41 / 35 空，空号 1..N 连续唯一；
- 答案字母都在选项范围内，无重复选项；
- 所有矩阵空位 3×3 且 `M·Mᵀ = I`；
- `changed_count` 与 `spec` 的差异项数逐条一致。

### 4.3 与独立构造对照

样本 1-01（地面→机体，纯俯仰 10°）：

```text
修复前 S:  [[0.9848, 0, -0.1736], [0.1736, 0, 0.9848], [0, -1.000, 0]]   侧向 → (-0.174, 0.985, 0)
修复后 S:  [[0.9848, 0.1736, 0], [0, 0, 1.000], [0.1736, -0.9848, 0]]     侧向 → (0, 1, 0)
独立 Rodrigues: [[0.9848, 0.1736, 0], [0, 0, 1.000], [0.1736, -0.9848, 0]]
```

修复后与不经过模型的 Rodrigues 构造逐元素相同（最大偏差 2×10⁻⁶）。

样本 1-01（机体→气流，α = β = 10°）：修复前 Sα 把机体侧向映射到 `(0, 0.985, 0.174)`，修复后映射到 `(0, 1, 0)`。

### 4.4 本轮答案零变化

绑定重构前后，三个 batch 的 `samples.jsonl` 与 `pilot_10/samples.jsonl` 哈希完全一致：

```text
ground_to_body      9CF11B7C…   (unchanged)
ground_to_track_air C1829B19…   (unchanged)
body_to_airflow     3B891793…   (unchanged)
pilot_10            57F8BB0A…   (unchanged)
```

原因是数据里的 Sα、Sβ、SθψΦ 等本来就取自“分段变换的起点系”，重构只是把这条规则写成“绝对方向 + 起点/终点”，并把直接变换与分段变换区分开。

## 7. 说明

1. 直接变换（机体→气流）与分段变换（机体→稳定、稳定→气流）现在是三个独立的有向转换：直接变换两端只用机体方向，分段变换各自用各自的起点系。
2. 复合矩阵 `Sαβ` 与 `Sμφγ` 按分段矩阵连乘得到（`Sβ·Sα`、`Sγ·Sμφ`），与手稿第 13 步一致；35 空考察的就是分步转换，不改成直接变换的公式。地面→气流同理。直接变换的绑定只用于模型的有向转换表与 `describe()`。
3. 转向的物理含义不变：逆向转换只差一个反号。
4. 风洞数据用的是 `body_frame_model.py`，不受本次改动影响。
