# 契约错误的频率、深度与危害度

本地故障只计 E1–E4。传播不单独成行。
频率 P 是两份自答里出现的份数 / 2。
危害度 C = P × Σ w。真实角和体轴力/力矩的权重是 3，弹性补偿是 2，等效力矩是 1。
只有写进最小修复集的故障才计入，包含终点自身的直接命中。
二元集合里的两个故障都拿该终点的全部权重。三元及以上的终点没有最小修复集，C 不加分，另列在「未解开」。
