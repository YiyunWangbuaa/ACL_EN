# LIMIT ANALYSIS FOR SYMBOLIC MULTI-STEP REASONING TASKS WITH INFORMATION PROPAGATION RULES BASED ON TRANSFORMERS

## 一句话
同一条语义不变的符号推理链，只因事实对在输入中的序列化顺序（置换 σ）不同，3 层 Transformer 的准确率就从约 90% 掉到约 20%——L 层模型的单遍推理步数被硬性限制在 [2^(L-1)−1, (3^(L-1)−1)/2] 之间，且上界能否达到完全取决于序列化顺序。

## 核心思想
- 把多步符号推理建模为「推理链 (a_m) + 置换序列化 σ + 推理起点」，提出四条信息传播规则（因果掩码、首层奇偶配对、同值匹配、残差并集），把 Transformer 的单遍推理刻画为层内跨节点并行传播；机制基础是 Buffer 存储 + 相邻位置匹配 + 同 token 匹配（induction head）。
- 单遍推理深度界：定理 6.1/6.2 给出每节点信息量 T^l(x) ∈ [2^(l-1)+1, 3^(l-1)+1]；推论 6.4 给出 L 层模型最大前向推理步数 S_p ∈ [2^(L-1)−1, (3^(L-1)−1)/2]。下界对应顺序排列的「二叉树」传播（链序任意置换均可达），上界对应特定「分形排列」的「三叉树」传播。
- 序列化顺序是决定因素：因果掩码下置换 σ 直接影响信息传播深度；上界在掩码条件下仍可达（附录 C 构造达界序列），附录 D 用循环矩阵构造出达到极限深度的 Transformer，证明界是紧的。
- 实验验证：3 层模型 4 步任务总准确率 46.1%（canonical 序列约 90% vs non-canonical 约 20%），5 步任务降到 25.1%（超出 (3^(3-1)−1)/2=4 的界，模型退化为猜测）；2 层模型见附录 E.7。并以此解释 Sanford et al. (2024) 中超出 log2 倍增范围的非零准确率。

## 支撑框架的位置
- **(c) 顺序敏感、深度受限：强支撑。** 同一依赖链、同一模型，仅事实对排列顺序不同 → canonical 约 90% vs non-canonical 约 20%（图 6）；推论 6.4 给出依赖深度（推理步数）与模型深度的硬界 2^(L-1)−1 ≤ S_p ≤ (3^(L-1)−1)/2，4 步可解而 5 步准确率塌缩至 25.1%，失败原因是依赖深度超出传播容量而非表示能力。
- **(d) 序列化 vs 图结构：强支撑。** 该文的推理链 (a_m) 即框架 G 中的路径型依赖 DAG，σ 即其顺序化：同一条链有 |σ| 种合法序列化，因果掩码使「图依赖必须顺序化」成为信息传播的支配因素，传播规则（Rule 1 掩码 + Rule 3 同值匹配）本身就是图依赖顺序化的形式化；上界仅对特定分形排列可达，说明序列化方案直接决定单遍内可解的最大依赖深度。
- **(a) 等价改写/表示扰动致错：部分支撑（类型受限）。** 置换 σ 保持推理链语义 (G,R) 不变、只改输入呈现顺序，属「等价改写」，致错幅度 90%→20% 是直接证据；但扰动类型是「事实句排序/序列化」而非框架 θ 中的「符号/坐标/单位/正方向」替换，符号层面扰动未被检验。
- **(e) 预算与结构层：弱/间接支撑。** 该文只分析单遍（无 CoT 预算消融），但可支撑「结构层瓶颈不由表示层资源修复」一侧：步数超过深度界时理论上单遍内不可解（与参数、训练充分性无关），实验 25.1% 接近猜测；同时给出相反方向的证据——层数预算 L 增加使推理容量按 2^(L-1)~3^(L-1) 指数增长，即深度预算对结构层也有收益，未观察到 A_S(B) 平台。其动机（CoT 过度思考浪费算力）提示 CoT 延长序列不改变单遍内在容量问题，但无直接实验。
- **(b) 规范化/重写的可证明有界性：不支撑。** 该文证明的是信息传播深度上下界（且界是紧的、可构造达界），与「规范化重写的终止/有界性」或「等价性检验的困难性」无关。

## 边界
- 计算模型：带因果掩码的单遍 decoder-only Transformer（单头注意力、充分大隐藏维），结论是单遍前向的信息传播上限，不覆盖 CoT 自回归多轮生成。
- 任务类：线性链式 bigram 推理（a_i→a_i+1），无环、无分支、无并行的 DAG 依赖；不直接外推到多跳 QA、树/图状依赖或规则冲突消解。
- 实验规模：仅 2–3 层小模型 + 符号 token，4/5 步任务；「训练能否学到」的上界行为只得到部分验证（高步数区间作者明言高准确率理论上不可达，故实验验证是部分的）。
- 上界推导中放松了掩码条件（后由附录 C 的构造补回紧性），故「任意排列下均达上界」不成立——恰恰相反，达界依赖特定排列，这是支撑 (c)/(d) 的关键，也意味着不能把 3^(L-1) 当作任意输入都可达的能力。
