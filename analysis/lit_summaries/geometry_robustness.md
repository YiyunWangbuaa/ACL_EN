# Measuring Representation Robustness in Large Language Models for Geometry

## 一句话
同一几何问题仅改表示形式（欧氏/坐标/向量，语义与约束等价即 (G,R) 不变、只动 θ），准确率差距最高达 14pp、Invariance@3 低至 0.044——表示扰动单独即可击穿 LLM，且重写干预只对高容量模型有效。

## 核心思想
- 构造 158 道高中几何题 × 三种语义等价表示（474 实例）的平行基准，用 Invariance@3（三表示全对比例）、Consistency@3（三表示输出相同比例）加 McNemar/bootstrap 在问题级隔离表示效应。
- Property 1–3 形式化指标：Acc_r = Invariance@3 + F_r（准确率分解为稳健分量与脆弱分量）；Invariance@3 ≤ min_r Acc_r（被最弱表示所界，"最弱环节"效应）。
- 向量表示是主导单点失败：CCW（欧氏/坐标对、向量错）模式比 WCC 多 2–5 倍；控制 token 长度与符号密度后表示变量仍显著（8/11 模型 p<0.05）。
- convert-then-solve（CTS）：先改写为欧氏再求解，高容量模型向量准确率最高 +52pp（Gemini-2.5-Flash 0.45→0.97，gap 14pp→2-3pp），而低容量 LLaMA-3.1-8B 几乎无变化（0.13→0.16，Inv@3=0.026）——重写只能修复表示层。

## 支撑框架的位置
- **(a) 强证据**：等价表示改写单独造成准确率差最大 14pp（Claude-Haiku 欧氏 0.60 vs 向量 0.46）；LLaMA-3.1-8B 的 Invariance@3=0.044（<5% 的问题在三种表示下全对）；E–V、C–V 比较 McNemar p<0.05；逻辑回归控制 token 长度与符号密度后表示变量对 8/11 模型仍显著——即只改 θ、(G,R) 不变时 LLM 确实出错。
- **(b) 双向证据**：正方向——CTS 显示"改写为规范表示"对高容量模型可修复表示扰动（向量 +52pp、gap 收窄至 2-3pp），Property 2 给出 Invariance@3 被最弱表示所界的形式化命题，可为"有界规范化"提供指标层面的界；反方向——低容量模型改写无收益（Inv@3 0.026），且答案等价性检验本身困难（"1/2"vs"0.5"、sqrt(48) vs 4*sqrt(3) 等非规范形式需人工裁定，约占 5214 实例的 15–20%），说明等价归一并非总是可自动、无条件完成。
- **(c) 部分证据**：H2/H4——向量解需要更长程序链（三角形面积：欧氏 1 步 vs 向量 2 个位移向量 6 次减法 + 叉积 6 乘 3 减 + 模长 3 平方 1 开方），链长增加与代数误差复合使失败概率上升；CCW 主导与"公式对、符号展开错"的定性案例表明模型对长程序链的执行深度受限。
- **(d) 弱**：未涉及图结构或序列化；仅区分欧氏（语言/关系式）与坐标、向量（代数/符号式）表示，不能直接支撑"图依赖需顺序化"。
- **(e) 类比证据**：CTS 需两阶段推理（转换+求解，每次实例推理开销加倍）——预算增加后高容量模型表示层差距收敛（gap 14pp→2-3pp、Inv@3 达 0.948），但低容量模型平台化（LLaMA-3.1-8B：0.13→0.16，WWW 模式仍主导）——预算可修复表示层、无法修复深层能力限制；注意原文干预是"先转换后求解"而非 CoT 长度控制，且零样本设定下未验证 CoT 本身的预算效应。

## 边界
- 文本-only、零样本、严格 JSON 输出，无 CoT/少样本/自一致性（作者自认这些策略可能缓解表示敏感性，不能外推"表示脆弱不可修复"）。
- 158 题来自印度高中教材（NCERT/RD Sharma/RS Aggarwal），向量脆弱性可能与训练分布（H3，纯推测）混杂；表面复杂度回归不能排除其他与表示相关的混淆。
- 变体由 Gemini Pro 生成、评测含 Gemini 2.5 Flash，存在同族污染风险；严格答案匹配会低估部分正确推理。
- 结论是"存在表示特定启发式依赖"，不证明模型无抽象几何推理；不可外推到图结构推理、多模态、证明与开放域任务。
