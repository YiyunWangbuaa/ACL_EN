# Lost in Reordering_Structural Sensitivity of Multilingual LLMs under Semantics-Prserving Perturbations

## 一句话
在自由语序语言（印地语、马拉雅拉姆语）上，两类保义句法扰动——受约束的成分重排与主动-被动语态转换——使 6 个 LLM 在 GSM8K 数学推理上一致显著掉点：LLM 依赖表层语序而非底层语义，缺乏"等价改写不变性"（compositional invariance）。

## 核心思想
1. 构造基准 IndicReStruct（GSM8k-Reordered / GSM8k-Voice）：把问题按语义凝聚词组分块后做受约束伪随机重排、或做主动-被动转换，语义保持不变（embedding 余弦相似度受约束重排约 98%，随机全打乱仅 87–92%），是对"语义保持等价改写"的直接压力测试。
2. 6 个 LLM × 4 种提示策略（0/1/3-shot CoT、Plan&Solve）在两种语言上全部一致掉点；对扰动数据做 LoRA/DoRA 轻量微调也回不到零样本提示基线——提示层与微调层干预均不能消除对表面句法实现的敏感性。
3. 归因（Gemma-2-9B-it 激活修补）：实体-数量错位（Entity/Quantity Misalignment）是头号错误类别；残差流修补在中间层（5–25 层）恢复效率最高、且"实体-数量组合"token 恢复率最高——失败源于模型内部对实体与数量关联组织（关系绑定）的破坏，而非纯算术计算错误。

## 支撑框架的位置
- **(a) 强支撑——等价改写确实让 LLM 出错**：这是全文的核心经验证据。零样本 CoT 下成分重排：Gemma-2-9B-it 印地语 76.30→61.78（↓14.52）、Llama-3.1-8B-it 56.63→25.42（↓31.21）；语态转换：Llama-3.1-8B-it 印地语 56.63→27.22（↓29.41）、Gemma-2-27B-it 马拉雅拉姆语 71.42→48.14（↓23.28）。所有模型、所有提示策略、两种语言无一例外掉点，且扩展到 ARC-Challenge 印地语（Gemma-2-27B-it 87.13→83.65）。(a) 的"反题"也被否定：等价改写带来的掉点不能用提示策略或轻量微调修复（见 (e)）。
- **(c) 强支撑——顺序/结构敏感与关系绑定瓶颈**：成分重排只改线性顺序不改语义，性能却大幅下降；错误分类学显示实体-数量错位为头号失败模式；激活修补因果性地证明中间层与实体-数量 token 决定答案能否恢复。这对应本框架中"依赖/绑定关系是推理瓶颈"的命题——破坏实体-数量的对齐即破坏 G 中的边绑定。
- **(d) 中支撑——LLM 是序列模型，依赖表层序列化**：自由语序语言中同一语义 (G,R) 的不同线性化给出不同答案（图 1：重排后 $18→$14）；结论明确断言模型"依赖训练中见过的表层结构规律而非组合语义理解"。这是"图/依赖结构必须顺序化，且顺序化方式本身成为敏感变量"的直接证据。
- **(e) 中支撑——预算/提示策略不修复该敏感性**：0/1/3-shot CoT 与 Plan&Solve 下掉点持续存在（如 Llama-3.1-8B-it 印地语 Plan&Solve 33.08 点跌幅）；DoRA 微调仅到 46.13%（Reordered）/ 51.25%（Voice），仍低于零样本提示基线 61.78% / 76.30%。即"更多示例、更优提示"这类预算性干预无法消除对表示/序列化层的敏感。注意：该文未对 CoT 长度做显式消融，(e) 属间接证据。
- **(b) 弱支撑——等价性检验本身困难（反面）**：保义性只能靠 embedding 余弦与 LLM-as-judge 代理验证；完全随机重排会摧毁语义（随机 vs 受约束重排相似度 87–92% vs ~98%），且错误类别中仍有"Question Reordering Semantics Drift"。说明重写/规范化必须受句法约束，无约束规范化不能保义——与"有界规范化需带约束与终止证明"的假设一致，但该文没有给出任何规范化可终止/有界的证明。

## 边界
- **命名错位**：该文的"structural"指表层句法实现（语序、语态）。按本框架 M(x)=(G,R,θ) 划分，词组成分重排主要扰动 θ（序列化/表示层），依赖关系本身未变；只有语态转换触碰 G 中的角色标定。因此不能把它当作"改变 (G,R) 依赖 DAG 后预算无法修复"的结构层证据——恰恰相反，它证明的是：连框架中最乐观的"表示层扰动可被有界规范化消解"这一点，当前 LLM 也尚未内生做到（必须外挂规范化/校验环节，而 (b) 又指出校验本身是难的）。
- 实验范围仅印地语、马拉雅拉姆语（均为 SOV 自由语序语言），任务仅 GSM8K 算术与 ARC 科学问答；未测长程多跳、符号推理、非自由语序语言。
- 重排是"词组成分级"受约束重排（保留语义凝聚组块与连词锚点），不是任意 token 级打乱；结论不能外推到完全无约束扰动。
- 无 CoT 长度/计算预算显式消融，对 (e) 的支持是"提示策略不变式"层面的，而非预算收敛曲线层面的。
