# Fragile Reasoning_A Mechanistic Analysis of LLM Sensitivity to Meaning-Preserving Perturbations

## 一句话
该文是"表示 vs 结构"分离最干净的实验对象：其扰动（人名替换、数字格式改写）只改 θ，(G,R) 完全不动，却造成 28.8%–45.1% 的答案翻转，且能否被"有界修复"取决于模型内部失败签名（localized 可、distributed/entangled 不可）。

## 核心思想
- 意义保持扰动 = 纯表示扰动：名称替换（符号维 θ）与数字格式改写（"$5"→"5 dollars"、"60%"→"60 percent"，单位/格式维 θ）均不改变数学结构（G,R 不变），是本框架"表示扰动"的标准实证构造。
- 失败呈架构特异签名：activation patching 恢复率 Llama-3 71.7%（localized）、Mistral 5.0%（distributed，冗余通路）、Qwen 0.0%（entangled，MLP 主导）——破坏性不在 θ 本身，而在模型内部如何传播 θ 差异。
- 级联放大机制（CAI）：翻转样本的层间 JSD 持续放大（Mistral 从 L4 的 ~1.7× 到末层 9.9×），稳定样本则衰减；表示扰动的错误经深度传播被放大而非自校正。
- 有界修复的分界：仅 localized 失败可被局部干预修复（steering 12.2%；仅 L3–5 层 FT、8.2% 参数恢复 11.3%）；distributed/entangled 停滞在 5–7%，ROME 权重手术为负（−1.1%）。

## 支撑框架的位置
- **(a) 强支撑**：等价改写/表示扰动让 LLM 出错的经验证据。677 组 GSM8K 配对样本上 flip rate：Mistral 45.1%、Llama-3 33.5%、Qwen2.5 28.8%；且 θ 内部有分层——数字格式（单位/符号格式）改写一致比人名（符号）替换更破坏（Mistral 63.1% vs 27.3%，其余两模型同趋势）。
- **(b) 部分支撑（作为反例/保留条件）**：框架假定表示扰动"应可被有界规范化消解"，本文表明该假定不能无条件成立——有界局部重写（steering 向量、少量层 FT）只在 localized 失败上有效（11–12%），对 distributed（5.2%）和 entangled（7.2%，ROME −1.1%）不消解。结论：θ 扰动能否被有界规范化消解，取决于模型内差异的传播结构，需按失败签名分类讨论。
- **(c)(d)(e) 无直接证据**：本文固定 (G,R)，不做依赖图/顺序/耦合扰动，不做图→序列化对比，不用 CoT 预算或长度控制（固定 prompt + 贪心解码，只看答案 token），不支撑 (c)(d)(e)。注意 CAI 的"深度放大"是网络内部层深度，不是任务依赖图的传播深度，不能迁移到 (c)。

## 边界
- 仅 7–8B 开源指令模型（Mistral-7B、Llama-3-8B、Qwen2.5-7B），规模外推未知；任务类仅 GSM8K 小学数学文字题，不能外推到证明、多步图依赖或结构扰动任务。
- 扰动只覆盖 θ 的两个子维（人名符号、数字格式），不涉及坐标、正方向等其他表示参数。
- 机械化分析子集仅每模型 60 个翻转样本；组件消融用零消融（非自然因果结构）；只分析答案位置 token，不追踪中间推理步。
- 修复手段恢复率低（≤12.2%），属于诊断性证据，不是可用修复方案。
