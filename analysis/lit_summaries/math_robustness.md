# AN INVESTIGATION OF ROBUSTNESS OF LLMS IN MATHEMATICAL REASONING_BENCHMARKING WITH MATHEMATICALLY-EQUIVALENT TRANSFORMATION OF ADVANCED MATHEMATICAL PROBLEMS

## 一句话
把等价变换拆成"表面重命名（只改 θ：语句/答案/参考证明路径全不变）"与"内核重写（证明 DAG 与高层 proof plan 按构造保持，只换数学设置与答案）"两族，证明 LLM 的主导弱点是把证明计划迁移到新设置，而非表示层脆弱——表示层与结构层的失败有可分离的实验签名。

## 核心思想
1. **GAP 诊断拆分**：T_surf 是标识符双射改名（只动表示 θ），T_kern 重采样数值/关系槽但保证高层 proof plan 不变；同一题目的成对变体使失败原因可在题内分离——表面掉而内核不掉 → 表示问题，反之 → 计划迁移问题。
2. **内核生成以证明 DAG 为中介**：官方解解析为 DAG（节点=中间断言，边=局部蕴含）→ 抽象为内容无关的方法标签 → 叶节点重采样 → 沿 DAG 扩散重实例化 → 还原为题目，plan 按构造保持；表面改名则由确定性后验证器保证等价性 by construction（纯字符串替换，无需判题器/证明能力）。
3. **经验主结果**（18 模型 × 1,051 道 Putnam 题，PutnamGAP 共 6,306 项）：内核重写崩塌最大——o3 51.5%→38.6%、gemini-2.5-pro 78.4%→63.5%，最强 5 模型仍比表面族平均多掉 10–12 pp；条件能力损失率中位数 L_kern=70% vs L_surf=40%（sign test p=7.6×10⁻⁶）。
4. **两种失败签名分离**：表面失败 = 自不一致（轨迹偏离模型自己的原解：self-anchor d=+0.75 → canonical-anchor d=+0.23 塌缩）；内核失败 = 策略漂移（轨迹偏离规范证明 plan，canonical-anchor d=+0.35）。专家解前缀（canonical_T2）显著救回表面失败（OR=3.21，p=8.9×10⁻⁹）但内核失败不显著。

## 支撑框架的位置
- **(a) 强证据**：纯改名（只扰 θ，(G,R) 不变）确实让 LLM 出错——DLC/DLM/GS 表面簇整体低于原题，自锚 d=+0.75 的自不一致签名（72/72 单元方向为正，69/72 p<0.05）；MATH L4–5 上 12/12 单元负向下降、8/12 显著，ALG514 93.6%→90.9%（DLC）/89.3%（GS）。即"表示扰动真实存在、需要被规范化消解"的独立经验证据。
- **(b) 双向支撑**：表示层——改名等价性由确定性后验证器按构造保证，零判题、零证明能力，等价于"θ 层规范化有界"；结构层——内核等价性检验本身困难：需 J=5 判题器 + T≤15 修复循环 + 双连击规则，仅得概率 soundness bound δ≤14ε^KJ<10⁻¹⁰（ε=0.08 时 δ<10⁻⁸），且依赖"验证严格易于求解"的信息不对称（核验给定证明链 vs 从零搜索解空间）。
- **(c) 支撑（注意方向）**：证明 DAG 的依赖结构是失败焦点——内核重写保持 plan/DAG、只换局部代数与设置，仍造成最大崩塌与策略漂移，且该差距不随模型强度收敛；说明瓶颈在 (G,R) 的再实例化/规则选择而非表示层。该文扰动的恰是 R 的实例而保 G，故证据指向"结构层再实例化难"而非"G 改变难"。
- **(e) 间接/部分支撑**：有界干预不对称——注入有限长度的专家解前缀显著修复表示层失败、救不了结构层失败（canonical_T2 vs own_T2：b=75, c=36, p=2.7×10⁻⁴，且 55–60% 表面失败仍未被救回）；轨迹长度三分位分层（最短三分位 d=+0.84 仍成立）排除长度假象。但该干预是"推理内容注入"而非推理预算/CoT 长度伸缩，且全文为单次零样本、无 test-time scaling，不能直接外推为"预算增大只改善表示层"的证据。
- **(d) 无直接证据**：论文用证明 DAG 做生成与 plan 保持，但从未测试"序列化 vs 图结构"对 LLM 推理本身的影响；其诊断反而要求可见推理链（序列化轨迹），暴露的是序列化依赖的局限。

## 边界
- 任务类假设：英文竞赛级（普特南）证明题，单次零样本通过、无 test-time scaling；结构性诊断要求可见推理链，排除只输出答案的模型。轨迹级"自不一致/策略漂移"分离仅在 PutnamGAP 上建立（MATH/ALG514 只验证了行为迁移）。
- 等价性保证的强度不对称：表面变体按构造等价；内核变体的等价性只靠单一模型家族（o3）判题器共识的概率界 + 10% 人工审计，非形式化验证（如 Lean/SMT）。
- 因果主张限于行为签名："自不一致/策略漂移"是可观测轨迹模式，作者明确声明不是对内部状态的断言。
- 不能外推：不能外推到简单任务（RRB 显示前沿模型对确定性文本扰动基本鲁棒），也不能声称增大推理预算能修复表示层——该文未做预算实验；"专家前缀救表面失败"也不构成有界规范化的算法实现。
