# Predictive Maps of Multi-Agent Reasoning_A Successor-Representation Spectrum for LLM Communication Topologies

## 一句话
"稳定性悖论"：同一规则系统 R、同一 12 步深度 T，只把通信图 G 从链式（纯串行）换成带聚合的星/网格，累积误差就减半（2094 vs ~1184/1241）——决定误差的是 (G,R) 层的组合方式（串行 vs 聚合），而非对该结构的任何"表示层"读数：线性谱（ρ=1 判链最稳）对串行漂移完全失明。

## 核心思想
- 多智能体 LLM 系统 = 有向通信图 G，后继表示 M=(I−γP)⁻¹（γ=0.9）作为结构的"预测图"，三个谱量各对应一种失效模式：谱半径 ρ(M)→漂移放大、谱间隙 Δ(M)→共识收敛、条件数 κ(M)→扰动鲁棒性。
- 稳定性悖论：链式拓扑 ρ(M)=1（线性意义上最稳）却在 100 次试验中累积误差最大（2094.34±843.05 vs 星 1184.24±951.91、网格 1241.00±950.01，H=58.02, p<0.001）；每个 agent 的微小偏差在纯串行组合中无平均地逐级前传，星/网格的聚合步起隐式平均作用抑制漂移——谱对这类非齐次漂移不可见。
- 仿射噪声模型给出闭式界 E[E_ceg] ≤ (2/3)C·σ/√k·T^{3/2}：误差随深度 T 超线性增长（结构层深度瓶颈），且 k 重聚合以 √k 倍抑制；链 vs 聚合预测比值 2，实测链/星=1.77、链/网格=1.69，均在抽样方差内。
- 结构层可证明有界：恶意叶权重操纵下 κ(M) ≤ (3+γ²(ℓ+1/ℓ+µ²))^{3/2}/(1−γ²)，尺度 Θ(ℓ^{3/2})；把单 agent 影响上限制为 W/ℓ 的规范化操作强制 µ=0，作为硬上界恢复良性条件数。

## 支撑框架的位置
- **(c) 依赖结构/顺序/图结构影响 LLM 推理（顺序敏感、深度受限）：强证据。** 任务规则本身即序依赖协议（"RULESET - apply in this exact order... Each rule requires the result of the previous"），且实验中只改变通信拓扑 G、保持规则 R 与步数 T 不变，E_ceg 三拓扑间差异 H=58.02 (p<0.001)。深度受限的直接公式：E[E_ceg] ∝ T^{3/2} 的上界推导（附录 A.3），即结构传播深度以超线性方式定价误差；链式拓扑逐步误差单调增长、星/网格轨迹平坦（图 5）。
- **(d) 序列化 vs 图结构：强证据。** 链 = 纯串行组合（12 个顺序 agent 无聚合），每个 agent 的"小非零偏差"被原样前传形成单调漂移；星/网格把同一计算插入聚合步骤（法官聚合/多数表决）即把每步噪声方差降为 σ²/k。作者明言"通信图中的顺序性是一种独立、可组合的漂移源，与单 agent 长度效应相互作用"（引 Dziri et al. 2023、Liu et al. 2024），即把图依赖串行化的方式是误差源本身，而非 θ 层问题。
- **(b) 规范化/重写可被证明有界：弱支撑（仅结构层类比）。** 该文给出两类有界性证明：仿射噪声模型对累积误差的闭式上界（深度 T、聚合数 k 的显式函数），以及 A.6 的影响上限规范化（cap 在 W/ℓ）强制 µ=0 并以良性 κ 为硬上界——说明"局部结构化修正 + 可证明有界"在该文的结构层成立；但这是对图边权/聚合的规范化，不是对 θ（符号/坐标/单位）重写的有界性证明，不能直接迁移到表示层。
- **(a) 不涉及。** ε=15.0 的 Value 扰动是输入扰动（改任务状态而非等价改写），全文无等价规则改写实验；per-agent 噪声是同一 (G,R) 上的解码随机性，不构成 θ 层表示扰动。
- **(e) 无实验证据。** 所有 agent 固定 250-token 预算，无预算/CoT 长度扫描；仅在相关工作处引用"推理随长度退化"文献并声称其链式结果与之"一致"（顺序性为独立漂移源），未验证预算只救表示层不救结构层。

## 边界
- 作者自认是案例研究：单模型族（Qwen2.5-7B-Instruct）、单任务族（12 步 JSON 状态追踪）、三个拓扑、每条件 100 次试验；三秩上的 Spearman 系数几乎无统计功效（r_s=1.0/0.5/−1.0 仅作秩一致性证据）。
- 仿射噪声模型假设 agent 间噪声 iid、转移规则 τ Lipschitz 常数 ≤1；共享基模型的系统性偏差（ρ_c→1）会使聚合增益坍缩为 1（附录 A.4，实测推断 ρ_c≲0.06），强非线性/尖锐分支规则下线性化失效——该界不可外推到规则系统本身有强耦合偏置的场景。
- 谱诊断作用于 agent 间通信图，而非 LLM 对任务的内部表示；对 θ 层（符号/单位/正方向改写）、预算分配、模型规模、闭源模型及链/星/网格之外的拓扑均无证据。
- 任务为合成、状态有界（Level∈[1,9]）、规则固定，误差只经显式通道传播（agent 上下文逐步重置）；不能外推到开放域推理或依赖关系动态变化的任务。
