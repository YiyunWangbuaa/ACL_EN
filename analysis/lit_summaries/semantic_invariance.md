# Semantic Invariance in Agentic AIpdf

## 一句话
该文用蜕变测试实测"只改表层表述、语义不变"的变换（改写、事实重排、扩写/缩写、语境改换）对 LLM 多步推理的影响，发现此类纯表示层扰动即可造成显著答案漂移（最稳健模型的稳定率也仅 79.6%），为框架"θ 扰动不改 (G,R) 但仍需显式有界规范化消解"的设定提供了最直接的量级证据。

## 核心思想
- 语义不变性的形式化：变换 τ 保持解集不变时要求 M(p)≡M(τ(p))；作者定义 8 条蜕变关系、分三类（结构：identity/paraphrase/reorder facts；冗长：expand/contract；语境：academic/business/contrastive），以 Score Delta、MAD（平均绝对偏差）、稳定率（|Δ|<0.05 的比例）和推理轨迹余弦相似度度量违反程度。
- 表示层扰动即可击穿推理：不改事实与逻辑的改写/扩写/语境改换即可造成普遍漂移；规模与稳健性倒挂——Qwen3-30B-A3B 最稳（MAD 0.049、稳定率 79.6%、语义相似 0.914），gpt-oss-20b 最差（MAD 0.211、稳定率 27.0%）。
- 扰动类型有特异性：DeepSeek-R1 对事实重排敏感（Δ=-0.171），"依赖输入顺序进行推理"；对比式扰动（引入干扰性对比项）是唯一使全部模型退化的变换（Δ 从 -0.088 到 -0.449），指向注意力机制面对干扰项的固有局限。
- 语义等价本身无形式化保证：变换的语义保持靠人工校验，答案等价只以 all-MiniLM-L6-v2 嵌入的余弦相似度近似；identity 基线（temperature 0.7）下采样方差已不可忽略，说明"表示层扰动可被自动吸收"的界并不默认存在。

## 支撑框架的位置
- (a) 强支撑：全文核心即"语义保持变换导致答案漂移"的经验证据——paraphrase/expand/contract/context 变换对应框架中 (G,R) 不变、仅 θ 变的表示扰动；具体数字：gpt-oss-120b 在对比式下 Δ=-0.449，gpt-oss-20b 稳定率仅 27.0%、MAD 0.211，最稳的 Qwen3-30B 仍有 20.4% 的变换未保持 |Δ|<0.05，证明表示扰动确实让 LLM 出错且量级不菲。
- (c) 强支撑：事实重排（对逻辑独立事实的呈现顺序置换）使 DeepSeek-R1 退化 Δ=-0.171、gpt-oss-20b 退化 Δ=-0.270，作者明确结论"依赖输入顺序进行推理"——顺序敏感性的直接证据；多步题（2-3 步至 5+ 步）下 gpt-oss 族 Δ 分布宽四分位距、大量离群点，显示顺序改变后处理过程不可预测。
- (d) 弱/间接支撑：StepScore 度量显式允许步骤重排（对参考步骤取 max 匹配），隐含承认同一解存在多种合法序列化；但论文未把依赖建模为 DAG、未测拓扑深度效应，reorder 仅置换逻辑独立事实，不能作为"图依赖需序列化"的直接证据。
- (b) 部分支撑（反方向）：论文未证明任何重写/规范化有界，反而给出"有界吸收"不成立的证据——0.05 容忍窗下最强模型稳定率仅 79.6%，identity 基线本身即有方差；等价性检验仅以嵌入余弦相似加人工校验代理，无形式化等价判定，侧面印证"等价性检验本身困难、只能近似"。
- (e) 无支撑：实验未操纵预算或 CoT 长度（max tokens 固定 1024、单次推理）；expand 帮助 Qwen3 却使 gpt-oss/DeepSeek 退化的不对称属输入语境冗长效应，不是推理预算效应，不能作为"预算改善表示层而非结构层"的证据。

## 边界
- 计算模型假设：LLM 作为"问题文本 → (答案, 推理轨迹)"的黑盒映射，无内部规划/依赖结构建模；结论仅对 7 个开源模型（Hermes/Qwen3/DeepSeek-R1/gpt-oss 四族）在单一平台（Nebius）、temperature 0.7、top-p 0.95、单次推理下成立，且无重复采样，不能完全区分变换效应与采样方差。
- 任务类：19 道多步科学推理题（物理、数学、化学、经济、统计、生物、微积分、优化；2-3 步至 5+ 步），无代码执行、多智能体或环境交互任务。
- 变换限于自然语言层面：paraphrase/context/verbosity，不含框架 θ 中的符号体系、坐标系、单位、正方向等数值表示扰动，不能外推到"符号级规范化"的有界性证明。
- 未建模依赖图：reorder 仅置换逻辑独立事实、未改变 (G,R)，因此其数字不能外推到结构扰动下传播深度/规则选择的瓶颈；contrastive 变换本身语义改变，是负控制而非表示扰动。
- 等价性为代理度量："语义等价"由 384 维 MiniLM 嵌入余弦相似度近似，无逻辑学保证，其数值不可当作形式化等价命题引用。
