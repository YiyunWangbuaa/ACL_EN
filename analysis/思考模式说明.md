# 思考模式：思维链是否回灌、为什么越来越慢、如何避免截断

对象：`cloze_eval.py` + `semi_auto_eval.py` 的调用链

## 1. 思维链不会回灌到 prompt

调用路径是：`_execute_chain` → `job_for` → `score_one` → `call_model`。

- `call_model` 每次只发一条 `{"role": "user", "content": prompt}`，并在发送前显式 `pop("reasoning_content")`；`reasoning_content` 只从**本次响应**里读出，写进记录的 `reasoning` 字段，不进入 messages，也不进入下一次 prompt。
- 多轮记忆（条件 B、D 用的“模型自己的原始输出”）只存**解析出来的答案值**：`memory[blank_id] = blank["prediction"]`，不是整段回复，更不是思维链。
- `_execute_chain` 里有一条断言：上一句的 `reasoning` 若出现在下一句的 prompt 里，直接抛错（“思维链被写回了下一句的输入”）。

实测：用一条 69 句的真实链跑假客户端（每句返回 400+ 字的“思考”），69 个 prompt 全部不含该文本，最大 prompt 4,798 字符。

另外补了两处加固：

- `_strip_reasoning`：如果某个供应商把思维链混进了正文，且与 `reasoning` 字段一致，评分与记忆前先剔除；
- `_memory_text`：记忆里每个答案截到 400 字符。原来单空句解析失败时会把**整段回复**塞进下一句前缀，长回复会把 prompt 越滚越大，现在有硬上限。

## 2. 为什么越跑越慢

不是思维链回灌，是**前缀本身在变长**：逐句条件 A/B/C/D 的“过程”要从子过程开头写到当前句，句子越靠后，prompt 越长。

实测（第一条样本，条件 A）：

| 子过程 | 首句 prompt | 末句 prompt | 增长 |
| --- | --- | --- | --- |
| 风轴系到体轴系（69 句） | 2,905 字符 | 5,639 字符 | +2,734 |
| 天平系到体轴系（23 句） | 2,884 | 4,308 | +1,424 |
| 地面系到机体系（24 句） | 2,482 | 3,315 | +833 |
| 地面系转航迹系和气流系（33 句） | 2,505 | 4,030 | +1,525 |

思考开启时，模型对更长的输入会做更长的推理，于是后段变慢；这是任务结构决定的，不是 bug。要缓解只能减少逐句调用的句数（例如改用分段或端到端条件），不能靠“清理思维链”。

## 3. 思维链吃满 max_tokens 导致答案被截断

`max_tokens` 含思维链（DeepSeek 官方口径），旧代码只记录 `finish_reason`，不处理 `length`。现在：

1. **不再切换预算**：思考开启时 `max_tokens` 固定为 65536，即原先 32768 的两倍。`finish_reason == "length"` 不再提高上限，也不改用 `low` 思考强度。
2. **截断即错误**：这次输出不作为答案。回复按空串评分，该句每个空都算错，记录 `unanswered: true`。这不是接口调用失败。
3. **记录字段**：`max_tokens` 记实际使用的值，`truncated` 表示这一次思维链被截断。

## 4. 建议

- 思考开启时固定发送 `max_tokens=65536`。显式传入其他值也会改成 65536。
- 思考关闭时的上限仍是 32768。思考开启后若仍是 `finish_reason=length`，该句按没有答复记错。
- 不要把 `max_tokens` 压到 2048 以下：`_resolve_max_tokens` 已把下限抬到 2048。
- 跑之前可以用 `analysis/measure_prompt_growth.py` 看目标子过程的 prompt 增长，估算耗时。
- 事后用记录的 `truncated` 与 `finish_reason` 统计截断率。截断的句子已经按错误计入，不再改预算重试。

## 5. 复现

```bash
python analysis/measure_prompt_growth.py   # 前缀增长实测
python analysis/test_reasoning_leak.py     # 69 句链，断言思维链不回灌
python analysis/test_truncation.py         # 思维链截断直接记错
```
