# 评价指标

口径与《FD-Eval_评测架构》第 4–7 节一致。链级强度看候选根到目标的路径上 \(\varphi\) 是否都有值：出现 \(\varphi=\bot\) 为关联。答案等于不等于 \(\varphi\) 只区分忠实和局部偏差，不决定可归因性。评测报告分为三层指标：**设计层**（数据集可诊断性）、**诊断层**（错误归因质量）、**因果层**（错误影响评价）。每层回答一个不同的问题，三层不合成一个分数。

---

## 1. 设计层指标：数据集可诊断性

设计层在模型评测前离线计算，衡量"这个数据集作为诊断系统的能力"。

### 1.1 可检测性（Detectability）

故障 \(f\) 可检测，当且仅当它的图可达集里至少有一个测点：

\[
\mathrm{det}(f)=\mathbf{1}\left[\exists m:\ m\in\mathrm{Reach}(f)\right].
\]

报告：可检测故障数 / 故障实例总数。可达集为空的故障单独列出。

### 1.2 可隔离性与故障隔离率（Isolability / FIR）

故障 \(f_i,f_j\) 分不开，当且仅当它们的二值支持列相同：

\[
f_i\sim f_j \iff \forall m:\ D_{f_i,m}=D_{f_j,m}.
\]

故障隔离率（FIR）= 可唯一隔离的故障数 / 可检测故障总数。支持列相同的故障构成**模糊组**，报告模糊组数量、最大组规模，以及组内是同类（DIR / RSN / EXE / ALG 之一）还是跨类。

### 1.3 因子暴露与值别名（latent / alias）

- **latent**：目标量直接因子中没有独立测点的个数。\(latent>0\) 表示存在被隐藏的错误来源。
- **alias**：不同因子赋值在某测点产生相同值的对数。\(alias>0\) 表示该测点值反解不回因子。

两者是设计审计，不保证可检测，只保证"不会因拆分过粗而漏掉主要错误来源"。

---

## 2. 诊断层指标：错误归因质量

诊断层回答"模型错误能否被解释、被解释得多强"。

### 2.1 归因覆盖率与未认定率

对错误测点集合 \(W\)，若某个候选故障实例能解释该测点，则记已归因：

\[
\mathrm{Coverage}=\frac{|\{m\in W:\mathcal{F}(m)\ne\emptyset\}|}{|W|}.
\]

未认定率 \(=1-\mathrm{Coverage}\)。未认定不必为零：保留未解释项比错误指定根因更严谨。

### 2.2 归因强度分布（因果 vs 关联）

对每个已得到链级标签的错误终点，归因强度看从候选根 \(w\) 到终点 \(t\) 的路径。路径上每个 \(\varphi\) 都有值（含 \(o\ne\varphi\) 的局部偏差）为因果；某处 \(\varphi=\bot\) 为关联。规则未运行且没有 \(\bot\) 的链是未解开，不记成关联。终点上只要有一条候选为关联，终点总强度记为关联。

因果归因率 / 关联归因率以这些错误终点的总强度为分子，分母是已经标上因果或关联的错误终点。没有链级标签的错误留在未认定里，不进这个分母。

### 2.3 传播深度与传播广度

对每个故障实例，在依赖图的潜在可达上计算影响范围。这里用结构后代，不用某一次观测里实际打中的测点；后者是第 3.2 节的影响范围。

- **传播深度** \(L_i^{\max}\)：从注入节点到最远下游节点的最长路径边数；
- **传播广度** \(D_i\)：可达节点（含注入节点）占答案节点数的比例。字段测点不重复计入，避免同一节点的多个字段把广度放大。

传播深度回答该错误在图上能传多远，传播广度回答能铺多宽。两者与发生度、危害度分开报告。

### 2.4 答案遮蔽率、随机性正确率与不可归因率

答案分类是五类，由答案对错和可归因性决定。可归因性看链上 \(\varphi\) 是否都有值，不看答案是否等于 \(\varphi\)。

| 答案 | 可归因性 | 分类 | 归因强度 |
| --- | --- | --- | --- |
| 对 | 父全对 | 一致性正确 | — |
| 对 | \(\varphi\) 有值，过程有错 | 可追溯答案遮蔽 | 因果 |
| 对 | \(\varphi=\bot\) | 随机性正确 | 关联 |
| 错 | \(\varphi\) 有值 | 可归因错误 | 因果 |
| 错 | \(\varphi=\bot\) | 不可归因错误 | 关联 |

答案遮蔽率 = 可追溯答案遮蔽 / 全部正确答案。随机性正确率 = 随机性正确 / 全部正确答案。这两率分开报，不合成一个「不可靠正确率」。终点再单独报一次。不可归因率的分子是链上出现 \(\varphi=\bot\) 的节点（随机性正确与不可归因错误），分母是规则给出了值或 \(\bot\) 的节点。无法解析、没有计算器、形状不符不进分子，也不单列成第六类。

## 3. 因果层指标：错误影响评价

因果层回答"哪些错误对最终目标危害最大"。

### 3.1 发生度（Occurrence）

\[
O(f)=\frac{\#\text{支持 } f \text{ 的评测运行}}{\#\text{可评测运行}}.
\]

发生度是频率，回答"该错误多常发生"，不与影响、危害混用。

### 3.2 影响范围（Reach）

\[
R(f)=\mathbb{E}\left[|\mathrm{ActualSupport}(f,o)|\mid f \text{ 被支持}\right].
\]

观测支持集取自这次运行的冲突记录：测点是与金标有差的测点，故障是该记录里的候选。它不包括仍然等于金标的潜在后代。候选里含签名打中、局部并集和保守归并，所以它宽于「该故障在这次运行里反事实打中的测点」。\(R(f)\) 是这个集合大小在 \(f\) 被支持的运行上的平均；程序尚未做这一步汇总，反查冲突记录即可得到。

### 3.3 目标影响与反事实贡献率（CR）

对目标测点 \(t\) 及候选故障 \(f\)，反事实修复 \(f\) 后 \(t\) 是否恢复：

\[
\mathrm{CR}(f,t)
=
\frac{\#\{o: y_{-f}\equiv y^\star\ \land\ f\text{ 出现}\}}
{\#\{o: f \text{ 出现}\}}.
\]

系统侧反事实（确定性重算）与模型侧反事实（重新调用模型）分开报告，分别记为 \(CE_{\mathrm{system}}\)、\(CE_{\mathrm{model}}\)。`compute_cr.py` 报的是风洞自答上的系统侧单修频率，引用时标明它是这一比值的近似。

### 3.4 不可分解度（Decomposability）

\(K^\star(t)\) 是系统侧反事实核：把若干槽改回金标并经 \(\Phi\) 重算后，\(t\) 恢复的最小槽集合，由 `minimal_fixes` 计算。它与诊断层从局部偏差读出的修复集分开，也不作为诊断是否成立的条件。

\[
\delta(t)=|K^\star(t)|.
\]

唯一最小核时，\(\delta(t)=1\) 为单因素，\(\delta(t)\ge 2\) 为多因素。存在多个最小核时，报告核集合和大小分布。没有算出最小核的终点列入未解开，不指定一个 \(\delta\)。

### 3.5 危害度（Criticality）

危害度综合频率与影响范围：

\[
C_i=P(E_i)\times\sum_j w_j\cdot\mathbf{1}[E_i\in K^\star(t_j)],
\]

其中 \(w_j\) 是目标权重，最终关注的终点权重最高。求和只取已经写出最小核的终点。没有最小核的终点不给 \(C_i\) 加分，并列入未解开。危害度、传播深度、发生度分三张榜报告。三张榜的名次可以不同：路径长而稀发，和路径短而进入高权重最小核，回答的是不同问题。

---

## 4. 报告约定

| 层 | 指标 | 回答 |
| --- | --- | --- |
| 设计 | 可检测性、FIR、模糊组、latent、alias | 数据集能不能诊断 |
| 诊断 | 覆盖率、未认定率、因果/关联率、传播深度/广度、答案遮蔽率、随机性正确率、不可归因率 | 错误能不能被解释、解释得多强 |
| 因果 | 发生度、影响范围、CR、不可分解度、危害度 | 哪些错误对目标危害最大 |

三层指标互补，不合并成单一分数；"危害度 / 传播深度 / 发生度"三榜分歧本身是结论，需在正文中分别呈现并解释。
