# 终点的最小修复集

分母是自答里答错的终点。金标前缀不在内。
修复只改上游的本地故障（E1–E4）。终点一律重算，不把终点自己的答案直接换成金标。
其它没被选中的本地故障保持模型原文。单修都不成功才做二元；二元也都不成功，记为三元及以上，不再往下搜。
计算器拒绝和重算后仍错分开计。拒绝表示留下的故障已经让计算器算不出终点。
