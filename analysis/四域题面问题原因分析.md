# 四域题面问题原因分析

> 复现口径：`signature.report('body-unmarked')` → 行 250、det1 182、det0 68（全部 `reason=稿件未改动`）。
> det0 = E1 63 行 + E3 5 行。运动学 `audit_composers_kinematics` → pose/F45 alias=22、joints/I16 alias=2。
> 四域均未见"依赖图缺边导致诊断断链"，以下问题全部落在**故障词表**与**测点可辨识性**两层。

---

## 1 风洞 E1（63 行）：注入器固定写"标准默认文本"

### 1.1 机制

`fault_instance._e1`：每个契约一行，注入器 = `standard.get(blank)`（标准稿文本）。

`_bind`：注入器里与样本金标相同的空被丢弃；若**全部**空都相同，行保留但注入为空转。

`signature._noop`：注入文本 == 样本金标 → det=0，`reason=稿件未改动`。

### 1.2 为什么大多数空相同

E1 行覆盖 74 个识别空。相对标准稿，各变体的识别层差异只有：

| 变体 | 与标准稿不同的识别空 |
| --- | --- |
| body-marked / body-unmarked | 2 个（7、94：ZTZ 手性符号） |
| roll-unmarked | 2 个（35、84：滚转正方向/正负） |
| alpha-marked | 3 个（21、155、179：迎角方向/正负） |

识别层答案由**轴绑定 + 手性**决定；16 项可变定义大多改应用层约定（迎角/滚转正方向、安装、补偿），不移动识别层的轴绑定。于是"用标准文本当错误值"在绝大多数识别空上并不是错误。

### 1.3 后果

- 单样本 E1 可检测 ≈ 1 行；63/69 行永久空转。
- det 分母被稀释：182/250 = 72.8%；若剔除 no-op 行则是 182/182 = 100%。

### 1.4 根因分层

| 层 | 原因 |
| --- | --- |
| 直接 | E1 注入器写"标准文本"，不是"该题另一个选项" |
| 结构 | E1 故障族假设"标准约定对该空是错的"，但单样本只移动极少数识别空 |
| 题面 | 识别空没有按"定义敏感度"筛选——74 个空里绝大多数对所有变异不变 |

## 2 风洞 E3（5 行）：见证值退化为金标

### 2.1 机制

`slot_signature._parent_alts`：替代值 = 同族兄弟空的值 + 标准值；先过滤掉与当前值相同的；**若无剩余，回填标准值**（341–342 行）。

`fault_instance._e3`：优先选"能推动最多计算器"的替代；若没有任何替代能推动，回退到 `accepted`（不动）的替代，保证每题有一行。

### 2.2 五行的实际取值

| 空 | 替代值 = 金标 | 为什么不变 |
| --- | --- | --- |
| 56 平置机体系中的空速坐标 | `[1, 0, 0]` | 平置体轴单位向量，与约定无关 |
| 58 代入用的平置空速单位向量 | `[1, 0, 0]` | 同上 |
| 85 天平系与机体系的滚转角差 | `γ_M - γ_tp` | 两角同向翻转，差不变 |
| 182 校心到模型顶点的距离 | `L + L_t - L_r` | 纯长度组合，按定义等于 Xr |
| 184 力矩参考点的体轴数学坐标 | `[Xr - Xg, Yg, Zg]` | 平置姿态下与上游中间量逐项相同 |

这 5 个空都是"几何/物理量"，不由 16 项约定决定；同族兄弟与标准值又都取同一值，**不存在语义不同的替代**。

### 2.3 后果

- 5 行永久空转。
- `_e3` 的"回退到 accepted"会为不可变空**保证**生成一行——行数虚增 5 行。

### 2.4 根因

E1 与 E3 共享同一个根因：**故障词表（标准文本 / 兄弟值 / 标准值回填）不是语义筛选过的扰动**。当某空对所有变异不变时，词表里没有任何"会改变下游"的替代，注入只能等于原文。

## 3 运动学 pose/F45：乘法测点的对称群

### 3.1 机制

`_pose_from_factors`：四个矩阵连乘（`R*S` 或 `S*R`）。`FACTORS["pose/F45"]` 中 R1、R2 的取值域都是 `{F41, F42}`；`rule` 的两个取值只差 S 的位置。

### 3.2 证据

32 组合 → 16 姿态：**10 对 + 2 组四 + 4 单体**（alias=22，与用户读数一致）。主碰撞：

- `(R1金,R2金) ↔ (R1异,R2异)`：乘积 `F41·F42 = F42·F41`，两因子同时换相互抵消——即"把 R1 和 R2 对调，姿态不变"；
- `(rule金) ↔ (rule异)`：S 与旋转部分可交换时，S 在前/在后等价，规则因子在 F45 上不可辨识。

### 3.3 根因

测点只观测**乘积**，而乘积对交换子不敏感。R1、R2 仅通过乘法进入且可交换时，F45 永远分不开二者。题面层把 5 个因子当独立维度，却只给了一个乘法测点；要分开需要能区分顺序的测点（非交换组合、部分积或独立中间量）。

## 4 运动学 joints/I16：单位阵退化

### 4.1 机制

`_joints_from_pose`：`S=I` 时 `S^T·D = D·S^T = D`，`erase` 的两个选项退化为同一表达式。

### 4.2 证据

8 组合 → 6（2 对碰撞，alias=2）；两对碰撞都发生在 `S=异（单位阵）`，仅 `erase` 不同。

### 4.3 根因

因子的取值域包含**退化点**（单位阵）。在退化点上另一个因子（消去方式）不可辨识。题面层：要么去掉 `S=I` 这个取值，要么在 `S=I` 时不设 `erase` 因子。

## 5 连带问题

### 5.1 三榜分歧（飞行力学、运动学）

`validate_pipeline._rank/_boards` 只比较三张榜的**榜首**：

- 频率 = 出现份数；
- 深度 = 下游跨度（最深终点依赖深度 − 自身深度）；
- 危害 = P × Σ 权重（真实角/体轴力 3、弹性 2、等效力矩 1）。

分歧的直接原因就是榜首不同：常见的组合是"高频浅层故障居频率榜首"与"低频深层/高危害故障居深度或危害榜首"。

题面因素：权重 3/2/1、"二元集合两成员都拿全权重"、无小核终点不给分——都会让危害榜与频率榜分离。

注意：按轻量方案，"分歧可见"是合格线的一部分，不算失败；但要区分"排序分歧（正常）"与"同一故障在三榜位置极端不一致（说明权重/核口径不匹配）"。

### 5.2 风洞 7/13 终点无小修复核

小修复核限定单修/2 元；长依赖链 + 多槽故障使"2 元内能修好"的终点变少。题面因素是终点到上游的依赖跨度大、故障组合空间大。要提高核覆盖，需缩短终点到可独立核对中间量的跨度，或把核搜索放宽到 3 元并给出代价。

## 6 建议（按优先级）

1. **给每个空打"定义敏感度"标签**（跨 21 个样本的取值变异）。E1/E3 只在敏感空上建行；不敏感空（182/184/56/58/85 等）列为"传播节点"或从故障库剔除。
2. **E1 注入器改成"该题另一选项"**（`_options()` 已有现成接口），或按"样本金标 ≠ 标准文本"过滤行。
3. **删除 `_parent_alts` 的"无剩余回填标准值"分支**；无语义不同替代时标"不可注入"（`不可注入` 已有先例），不计入 det 分母。
4. **E3 选替代时加硬约束**：必须至少推动一个测点（`_outcome` 预检），否则取负/反号/换 family，仍不成立就标不可注入。
5. **运动学**：给 pose/F45 增加顺序敏感测点（或把 R1/R2 改成不可交换的两轴）；joints/I16 去掉 `S=I` 取值或在该取值下删除 `erase` 因子。
6. **指标口径**：det 分母固定为"可注入行"，报表分列"可注入率 / 检出率 / 可诊断率"，避免 no-op 行稀释。

## 7 与"表示—结构分离"的对应

- E1/E3 的 68 个 no-op：故障在语义层是**恒等变换**——注入前后任务语义对象不变，下游自然无新症状。这属于"表示扰动"类的退化情形，不构成结构扰动。
- F45/I16 的碰撞：测点无法区分某些因子组合，属于**可辨识性**问题（alias），与故障传播无关。
- 四域均无缺边断链，说明图传播层是健康的；问题集中在故障词表（no-op）与测点选择（alias）。
