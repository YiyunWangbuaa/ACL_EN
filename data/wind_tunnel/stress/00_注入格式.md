# 注入到模型的正式数据格式

一次调用评测一句话。每句只有一个待填槽。输入由五段组成，顺序固定。

1. 作答要求：所有答案都放在 JSON 对象中，键是空的编号，值是答案，例如 {1:A}。分步问答每句只有一个空，输出一个 JSON 对象，例如 {1:A}。端到端问答才把整条过程的全部答案放进同一个对象。选择题的值是字母，不加引号。公式、矩阵、向量、表达式和距离必须用英文双引号包成字符串，例如 {11:"[[1, 0, 0], [0, 1, 0], [0, 0, 1]]"}。不输出句子原文，不解释。
2. 【定义声明】该条数据的完整定义。
3. 【物理常识】下面这段固定文字，每次都附上。
4. 【子过程】当前句所属子过程的名称。
5. 【过程】从该子过程开头写到当前句的句号。这一句之前的槽替换成选项所指的原文，例如 XFD、正装，不写 A、B 这样的字母。这一句里的每个槽都写成待填槽。句号之后的正文不出现。这是条件 A。计分用的标准答案仍是字母。

待填槽只有三个字段：{ID:编号, 选项:A：选项1；B：选项2, 输出格式:格式名}。没有选项时写“选项:无”。待填槽不包含标签，也不包含答案。

每次注入在过程之后附上【输出】。其中写明每个待填槽的 JSON 形式，并给出输出示例。示例只说明字符怎么排，不是该槽的答案。有选项时，待填槽把选项写成 A：选项1；B：选项2，模型输出 {编号:字母}。计分时取出 JSON 的值；正确字母、选项原文，以及能唯一对应正确选项的片段，都算命中。公式类答案去掉外层双引号后再比对。

各条审阅稿展示的是同一条过程的全文。其中每个槽额外写出标签和答案，这两项是审阅字段。人可以据此理解：评测哪一句，就把那一句里的槽都换成待填槽，把更早的槽换成答案，并在句号处结束。

四个逐句条件共用同一模板、同一句序，并在每个子过程开头重新开始。A：空前写入选项原文，句号后截断。B：空前换成模型上一句的原始输出，不纠正、不归一化；调用失败或空返回也原样放进下一句。C′：空前仍是选项原文，句号后的后续正文保留，其中的空继续待填、不预填答案。C″：空前是模型自己的原始输出，同时保留后续正文。A 与 B 只差前缀来源。A 与 C′ 只差有没有后续正文。

空的编号按子过程顺序连续排列，从 1 排到 194：风轴系到体轴系 1–78，天平系到体轴系 79–110，天平系到风轴系 111–174，力矩参考点 175–194。不再在每个子过程里从 1 重新编号。

D 是端到端。每个子过程单独一次调用，正文从开头保留到结尾，每个空都是待填槽，不预填答案。模型只输出一个 JSON 对象，键使用上面的连续编号。

## 物理常识

轴向正方向、法向正方向、侧向正方向分别是前方、上方、右侧。模型轴向的正方向、机体轴向的正方向、天平轴向正方向、风洞轴向的正方向都是这个绝对前方，不是坐标轴的正方向。单独变换迎角时，旋转轴是绝对侧向轴。单独变换侧滑角时，旋转轴是绝对法向轴。单独变换滚转角时，旋转轴是绝对轴向轴。各角的正方向以定义声明为准。坐标系转换采用被动变换。姿态角采用动轴内旋。

## 输出格式名

- 无：选择题。值只写选项字母，不加引号，不写选项原文。 示例：甲
- 矩阵：输出一行3×3矩阵，形如[[a, b, c], [d, e, f], [g, h, i]]。逗号后恰好一个空格。元素为整数，或由cos、sin和本题角度符号组成的表达式。乘号用*。不要换行，不要使用LaTeX。 示例：[[cos(θ), 0, -sin(θ)], [0, 1, 0], [sin(θ), 0, cos(θ)]]
- 向量：输出一行三个分量，形如[a, b, c]。逗号后恰好一个空格。分量为整数或符号表达式。不要换行。 示例：[0, -1, 1]
- 表达式：输出一行符号表达式。乘号用*，除号用/。三角函数写成cos(α_M)这种形式，括号内不留空格。负号直接写在项前，如-sin(α_M)。不要使用LaTeX，不要写等号。 示例：cos(θ) - sin(θ)
- 距离：输出一行由L、L_t、L_r用加号或减号连成的距离表达式。加号和减号两侧各留一个空格。 示例：L - L_t + L_r
- arctan：输出一行，且只能有一个arctan。分子和分母都必须为正；角度正负写在整个arctan外面。正角度写成arctan((分子)/(分母))，负角度写成-arctan((分子)/(分母))。不要让分子和分母同时为负，不要把负号放进内部。 示例：-arctan((cos(θ))/(sin(θ)))
- arcsin：输出一行，且只能有一个arcsin。分子必须为正，分母保持为正；角度正负写在整个arcsin外面。正角度写成arcsin(分子)，负角度写成-arcsin(分子)。不要让分子为负，不要把负号放进内部，不要写成分式。 示例：arcsin(cos(θ))
- 力臂：输出一行，形如-CN·Xg/L_RT。力系数与力臂之间用中点·。负号写在整个式子最外侧。力臂内部必须为正，表示额外力矩的绝对值，不要把负号写进力臂。力系数只能是CA、CZ、CN之一。力臂由Xg、Yg、Zg、Xr组成；力臂含减法时加圆括号。分母保持L_RT。不要留下字母C或L_c，不要写等号。 示例：-CN·Xg/L_RT

绝对方向

- 侧向：机体的左右轴。正方向朝右。左侧是其反方向。

- 侧向：风洞水平横轴。正方向朝右。左侧是其反方向。
天平的三轴六方向与风洞重合，不另设指向，也不随模型正装或反装翻转。天平前方、后方、上方、下方、右侧、左侧分别就是风洞的前方、后方、上方、下方、右侧、左侧。天平轴向、法向、侧向分别就是风洞轴向、法向、侧向。天平绝对轴向正方向是前方，绝对法向正方向是上方，绝对侧向正方向是右侧。天平坐标轴 XTP、YTP、ZYP 的正方向由后面的坐标轴声明给出，可以与绝对正方向相同，也可以相反。
