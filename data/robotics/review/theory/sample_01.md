- 表达式：一行。D*[a, b, c] 表示 D 左乘该列向量。不要展开 D。示例：D*[L, 0, 0]

# 正运动学样本

## 定义声明

固定约定
- 向量用列向量表示。父坐标系分量等于矩阵乘子坐标系分量。三个坐标系都是右手系，X、Y、Z 按这个顺序书写。
- 绕 X、Y、Z 的旋转记为 Rx、Ry、Rz。行和列按 X、Y、Z 排列。
- Rx(θ)=[[1, 0, 0], [0, cos(θ), -sin(θ)], [0, sin(θ), cos(θ)]]。
- Ry(θ)=[[cos(θ), 0, sin(θ)], [0, 1, 0], [-sin(θ), 0, cos(θ)]]。
- Rz(θ)=[[cos(θ), -sin(θ), 0], [sin(θ), cos(θ), 0], [0, 0, 1]]。
- 球腕姿态 R=Ry(q1)*Rz(q2)*Rx(q3)。最先转动的矩阵写在最左侧。
- 安装矩阵 S=[[1, 0, 0], [0, 0, -1], [0, 1, 0]]。它把工具系分量映射到球腕系分量。
- 工具相对基座的姿态 D=R*S。
- q1 的范围是 -60° 到 60°。q2 和 q3 的范围是 -90° 到 90°。

参考方向与坐标角
参考方向是基座 X 轴正方向，在基座系中为 [1, 0, 0]。它在工具系中的分量是 D 的转置乘这个列向量。记该分量为 [x, y, z]。
- α=arctan(-y/x)。本例 x>0，主值取 (-90°, 90°)。
- β=arcsin(z)。
- γ：记 t 为 D 的第一列，n 为 D 的第二列，e_Y=[0, 1, 0]。u=(e_Y-(e_Y·t)*t)/||e_Y-(e_Y·t)*t||。令 r=t×u。γ=atan2(n·r, n·u)。t 与 e_Y 平行时，γ 未定义。

平移
球腕原点与基座原点重合。工具原点相对球腕原点的工具系分量为 [L, 0, 0]。它在基座系中的位置是 D 乘这个列向量。

本例关节角
q1=0°，q2=30°，q3=-60°。

## 物理常识

列向量，矩阵左乘。转置把基座分量映到工具系。D=R*S。S 已给出。参考方向是 [1, 0, 0]。α 由 -y/x 决定，β 由 z 决定，γ 由 t、n 和 e_Y 决定。工具原点偏移是 [L, 0, 0]。

# 逆运动学样本

本样本单独送入。定义中不出现正样本的关节角，也不出现 D 的数值。

## 定义声明

固定约定
- 向量用列向量表示，矩阵左乘列向量。
- R=Ry(q1)*Rz(q2)*Rx(q3)。Rx、Ry、Rz 的元素与正样本定义相同。
- S=[[1, 0, 0], [0, 0, -1], [0, 1, 0]]。
- D=R*S。D 把工具系分量映射到基座系分量。
- q1 的范围是 -60° 到 60°。q2 和 q3 的范围是 -90° 到 90°。
- 唯一解只使用 -90°<q2<90°。q2=±90° 仍在机械范围内，但不纳入唯一解。
- 参考方向是基座 X 轴正方向 [1, 0, 0]。它在工具系中的分量是 D 的第一行。
- 记该分量为 [x, y, z]。α=arctan(-y/x)，β=arcsin(z)。
- γ：记 t 为 D 的第一列，n 为 D 的第二列，e_Y=[0, 1, 0]。u=(e_Y-(e_Y·t)*t)/||e_Y-(e_Y·t)*t||。令 r=t×u。γ=atan2(n·r, n·u)。t 与 e_Y 平行时不由这三个角求关节角。
- 本样本不给出关节角，也不给出 D 的数值。
- 记球腕姿态为 H，元素为 hij，行号在前，列号在后。在 -90°<q2<90° 上，q1、q2、q3 由 atan2(-h31, h11)、atan2(h21, sqrt(h11^2 + h31^2))、atan2(-h23, h22) 提取。

给定角度
三个坐标角是 arctan(1/2), arcsin(1/4), arcsin(1/2)。
由三个方向角求唯一关节角，只在 -90°<α<90°、-90°<β<90°、D 的第一列不与 e_Y 平行、且 -90°<q2<90° 时进行。

## 物理常识

t 与 e_Y 平行时，γ 未定义。唯一解只使用 -90°<q2<90°。消去安装使用 D 乘 S 的转置。
