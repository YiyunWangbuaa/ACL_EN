# Vision main experiment

One standard definition and nine single-definition perturbations. Each item is one object-and-stereo manuscript, 165 blanks, injected once.
The basic-theory stage is not included. The older two-stage manuscripts in data/vision/review/scene stay on disk and are not the entry for this experiment.
The single-definition perturbation is written at the start of each manuscript and in factors.json.

- Data 01: single-definition perturbation: none.
- Data 02: single-definition perturbation: world frame.
- Data 03: single-definition perturbation: object frame.
- Data 04: single-definition perturbation: camera-1 frame.
- Data 05: single-definition perturbation: camera-2 frame.
- Data 06: single-definition perturbation: camera azimuth.
- Data 07: single-definition perturbation: camera pitch.
- Data 08: single-definition perturbation: camera roll.
- Data 09: single-definition perturbation: mechanism pitch.
- Data 10: single-definition perturbation: mechanism azimuth.
