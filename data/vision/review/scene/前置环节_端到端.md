# 端到端审阅 · 机器视觉基础理论

这是纯基础理论 final-e2e 实际提出的四道题。过程名是机器视觉基础理论。世界坐标系就是相机1系。顺序是相机1系到相机2系、直线上的点及其反对称矩阵、方向向量、射线方向与目标点反解。R21 与 A 组空 37 是同一问，t21 与 A 组空 43 是同一问，P_c1 与 A 组空 47 是同一问，[P_c1]_× 与 A 组空 50 是同一问，P_c2 与 A 组空 49 是同一问，[P_c2]_× 与 A 组空 51 是同一问，d_w 与 A 组空 52 是同一问。题 4 的 d1、d2、X_c1、约束方程、叉乘向量、λ1、X_w 分别与 A 组空 56 至 62 是同一问。

四道题的定义声明各用该样本自己的声明，与同号填空审阅稿相同。下面先列题面，再按样本列标准答案。

## 题面

### 题 1 · R21、t21

相机1系就是世界系。相机2的方位角、俯仰角、滚转角为 ψ2、θ2、φ2，光心在相机1系中的坐标为 C2=(x2,y2,z2)。现在需要根据这些角度、光心坐标和当前坐标轴定义，推导相机1系到相机2系的旋转 R21 和平移 t21。给出 R21 和 t21。

R21 写入键 37，t21 写入键 43。

### 题 2 · P_c1、[P_c1]_×、P_c2、[P_c2]_×

直线上的点在相机1系中的坐标为 P_c1，以向量形式表示。P_c1 的反对称矩阵为 [P_c1]_×，以矩阵形式表示。该点在相机2系中的坐标为 P_c2，以向量形式表示。P_c2 的反对称矩阵为 [P_c2]_×，以矩阵形式表示。这条直线平行于相机1光轴正方向，该点沿相机1法向正方向，到光心的距离为 L。相机1系就是世界系。相机2的方位角、俯仰角、滚转角为 ψ2、θ2、φ2，光心在相机1系中的坐标为 C2=(x2,y2,z2)。现在需要根据距离 L、这些角度、光心坐标和当前坐标轴定义，给出四者的展开式： P_c1、[P_c1]_×、P_c2 和 [P_c2]_×。

P_c1 写入键 47，[P_c1]_× 写入键 50，P_c2 写入键 49，[P_c2]_× 写入键 51。

### 题 3 · d_w

相机1系就是世界系。相机1图像直线为 l=(K1·S1)^(-T)·[P_c1]_×·d_w，相机2图像直线为 l=(K2·S2)^(-T)·[P_c2]_×·R21·d_w。直线平行于相机1光轴正方向，方向向量 d_w 是该正方向在相机1系中的单位向量。现在需要给出 d_w 的展开式。d_w 单独展开成向量，不要与 (K1·S1)^(-T)、[P_c1]_×、R21 相乘，不要给出合并后的直线 l。给出 d_w。

d_w 写入键 52。

### 题 4 · d1、d2、X_c1、约束方程、叉乘向量、λ1、X_w

相机1、相机2图像上目标点的齐次坐标分别为 [u1,v1,1]、[u2,v2,1]。相机1系射线方向 d1=(K1·S1)^(-1)·[u1,v1,1]^T，相机2系射线方向 d2=(K2·S2)^(-1)·[u2,v2,1]^T。现在需要给出这两个射线方向各自的展开式,写成向量形式。然后完成目标点反解。目标点在相机1系中的坐标 X_c1 沿射线方向 d1，λ1 为深度。X_c1 从下列选项中选择：A. X_c1 = λ1·d1；B. X_c1 = d1 + λ1；C. X_c1 = λ1 + d1；D. X_c1 = d1 − λ1。两个相机看到同一目标点，相机1系到相机2系的变换为 X_c2=R21·X_c1+t21。约束方程从下列选项中选择：A. λ2·d2 = R21·λ1·d1 + t21；B. λ2·d2 = R21·λ1·d1 − t21；C. λ2·d2 = R21^T·λ1·d1 + t21；D. λ1·d1 = R21·λ2·d2 + t21。在约束方程两侧叉乘一个向量可消去 λ2，得 d2×(λ1·R21·d1+t21)=0。叉乘的向量从下列选项中选择：A. d2；B. d1；C. R21·d1；D. t21。在采用最小二乘准则、且 d2×R21·d1 ≠ 0 的条件下，由 d2×(λ1·R21·d1+t21)=0 求使残差平方最小的 λ1。λ1 从下列选项中选择：A. λ1 = −(d2×t21)·(d2×R21·d1) / |d2×R21·d1|²；B. λ1 = (d2×t21)·(d2×R21·d1) / |d2×R21·d1|²；C. λ1 = −(d2×t21) / (d2×R21·d1)；D. λ1 = (d1×t21)·(d1×R21·d2) / |d1×R21·d2|²。目标点在相机1系中的坐标 X_c1 已知。相机1系就是世界系，所以它在世界系中的坐标 X_w 从下列选项中选择：A. X_w = X_c1；B. X_w = R21^T·(X_c1 − t21)；C. X_w = R21·X_c1 + t21；D. X_w = X_c1 + t21。给出 d1、d2，并给出 X_c1、约束方程、叉乘向量、λ1、X_w 的选项字母。

d1 写入键 56，d2 写入键 57，X_c1 写入键 58，约束方程 写入键 59，叉乘向量 写入键 60，λ1 写入键 61，X_w 写入键 62。
